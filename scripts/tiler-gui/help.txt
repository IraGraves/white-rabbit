                             that match the tilesetGlobPattern          [string]

                             validated input file should be written     [string]

                             file name of the report will be derived from the
                             input file name, and be written into the same
                             directory as the input file.              [boolean]
  -f, --tileContentFile      The tile content input file path           [string]
